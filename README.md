# Explainable Quantum Artificial Intelligence for Target Deconvolution

## Requirements

```bash
pip install -r requirements.txt
```

## Usage

```bash
python scripts/run_hwang.py --data data/prepared --annotations data/annotations --output outputs
```

## Data

Prepared features are derived from [RxRx3-core](https://huggingface.co/datasets/recursionpharma/rxrx3-core). Compound–gene annotations are from [EFAAR benchmarking](https://github.com/recursionpharma/EFAAR_benchmarking).
